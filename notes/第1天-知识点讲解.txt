============================================================
一、知识点 1：变量与数据类型
============================================================

1.1 变量是什么

变量 = 给一个值起个名字，以后用名字就能找到它。

比喻：像给抽屉贴标签。你把东西放进抽屉，贴上标签写着「九门素材」，
      以后要拿就说「把九门素材那个抽屉给我」，
      不用每次都描述「那个木头色的、第三个、里面装着民国资料的抽屉」。

写法：

    site_name = "墨阁"

这一行读作：把右边的 "墨阁" 装进左边这个名字叫 site_name 的盒子里。

最重要的一个认知：

    = 在这里不是数学里的「等于」，是「赋值」—— 把右边的装进左边。

    数学里 x = 5 表示 x 和 5 是一回事；
    程序里 x = 5 表示「把 5 存到 x 里」，x 以后还能改。

    x = 5
    x = 10
    print(x)      → 输出 10。后一次赋值把前一次盖掉了。


1.2 四种数据类型

Python 里的值分类型。今天你只需要认识四种：

    字符串 str     文字。必须用引号包起来。
                   "墨阁"     '九门旧事'     "2026"

    整数 int       不带小数点的数。
                   22     0     -5     10000

    小数 float     带小数点的数。
                   3.14     0.5     -1.5

    布尔 bool      只有两个值：True  和  False

注意几个零基础高频错：

  · 引号：单引号双引号都行，但要成对，而且必须是英文引号。
    中文引号 “ ” 会让程序直接报语法错 —— 长得像，但程序不认。

  · True / False 首字母必须大写。写成 true 会报错（程序不认识这个小写的名字）。

  · 数字加了引号就变成文字了：
        22      是整数，能算数
        "22"    是字符串，是「两个字」，不能算数

怎么知道自己手里的值是什么类型 —— 用 type()：

    print(type("墨阁"))      → <class 'str'>
    print(type(22))          → <class 'int'>
    print(type(3.14))        → <class 'float'>
    print(type(True))        → <class 'bool'>

现在不用懂 <class 'str'> 这个写法，看后面的单词就行：str / int / float / bool。


1.3 新手最大的坑：字符串和数字不能直接相加

    age = "22"        # 加了引号，这是字符串
    print(age + 1)    # 报错！

报错信息长这样：

    TypeError: can only concatenate str (not "int") to str

意思：字符串只能和字符串拼在一起，不能和整数加。

因为对程序来说，"22" 不是一个数，是「两个字」（字符 '2' 和字符 '2'）。
"22" + "33" 的结果是 "2233"（把字接起来），不是 55。

你工作台里 py1 的 why 写的正是这事：
「不懂类型，后面会频繁遇到『字符串加数字报错』这类问题。」

记一句话就够了：引号决定了它是文字还是数字。


1.4 f-string：把变量塞进句子里

这是 Python 打印东西最常用的方式，今天必须练到有肌肉记忆。

    site_name = "墨阁"
    print(f"欢迎来到{site_name}")

输出：

    欢迎来到墨阁

三个要点：

  · 引号前面有个小写字母 f —— 这是灵魂，少了它大括号里的东西不会被替换。

  · 变量用大括号 {} 包起来。

  · 大括号里可以直接写算式：
        print(f"一年有 {365 * 24} 小时")

如果没有那个 f：

    print("欢迎来到{site_name}")     → 输出：欢迎来到{site_name}
                                        （没替换，全是死的文字）

对比着写一遍，你就记住了。

二、知识点 2：列表 list
============================================================

2.1 列表是什么

列表 = 一排有顺序的东西，用中括号 [] 包起来，逗号分隔。靠「位置」取东西。

比喻：像一列车厢。每节车厢有编号，从头开始数。

    titles = ["九门旧事", "二月红传", "陈皮阿四"]

这一行：一个列表，里面装着三个字符串。


2.2 四个动作（你工作台 py2 的 key 就是这四个）

    titles = ["九门旧事", "二月红传", "陈皮阿四"]

    titles[0]                 → "九门旧事"                    取第一个
    titles[-1]                → "陈皮阿四"                    取最后一个
    titles[0:2]               → ["九门旧事", "二月红传"]       取前两个（切片）
    len(titles)               → 3                             一共几个
    titles.append("长沙夜雨")                                  往末尾加一个

术语先混个脸熟：

    titles[0]      这种带中括号的写法叫「索引」
    titles[0:2]    这种带冒号的写法叫「切片」
    append         是「往末尾追加」

切片有个反直觉的地方：

    titles[0:2]  拿的是第 0 个和第 1 个，**不包含第 2 个**。这叫「含头不含尾」。

    记法：0:2 表示「从 0 开始，数到 2 之前停」。


2.3 最大的坑：编号从 0 开始

零基础在这里翻车的比例最高。

    titles = ["九门旧事", "二月红传", "陈皮阿四"]
    #            第 0 个      第 1 个      第 2 个

    titles[0]    → "九门旧事"      第一个是 0，不是 1
    titles[1]    → "二月红传"
    titles[2]    → "陈皮阿四"
    titles[3]    → 报错！IndexError: list index out of range

为什么从 0 开始？这是计算机几十年的老规矩，原因不用深究，
但要养成习惯：看到 [0] 就是第一个，看到 [-1] 就是最后一个。

[-1] 特别好用：不用管列表里有几个，-1 永远是最后一个。
你项目里「取最新一条素材」就靠这种取法。


2.4 在你项目里的出处

打开 backend/db.py，找这三行：

    第 283 行   sql = ["SELECT DISTINCT m.* FROM materials m"]

        一个列表，装着 SQL 语句的片段。为什么用列表装？
        因为后面的条件（按标签筛、按关键词搜）要一段一段往里加，
        最后用 " ".join(sql) 拼成完整语句。
        列表天生适合「慢慢往里加东西」这种场景。

    第 284 行   params = []

        空列表。空的也要先建好，后面才能 append。

    第 198 行   return [r["name"] for r in rows]

        这是「列表推导式」，把 for 循环压成一行的高级写法。
        今天不用懂，明天学了 for 回来看就明白了。

三、知识点 3：字典 dict
============================================================

3.1 字典是什么

字典 = 一堆带标签的信息，用大括号 {} 包起来，靠「名字」取东西。

比喻：像一张病历卡或者快递单。上面有「姓名」「年龄」「地址」这些栏目，
      你要找收件人，是按「姓名」这个栏目名去找，不是按「第几行」去找。

    material = {
        "标题": "九门旧事",
        "类型": "同人短篇",
        "来源": "九门资料库",
        "标签": ["民国", "师徒"],
    }

读法：这个字典有 4 个「键值对」。

    "标题" 是键（key），"九门旧事" 是它的值（value）。


3.2 取值

    material["标题"]     → "九门旧事"
    material["标签"]     → ["民国", "师徒"]

注意：取字典用中括号 + 引号包起来的键名。
为什么键名要加引号？因为它是一段文字（字符串）。
Python 里也允许不加引号的写法，但那是另一种东西，今天不碰。


3.3 今天最重要的一句话：列表 vs 字典

    列表靠「位置」找：  titles[0]          → 给第几个
    字典靠「名字」找：  material["标题"]   → 给哪个栏目

什么时候用哪个：

    一堆同类的东西、有先后顺序     → 列表    （书单、文件列表、标签列表）
    一个东西的多个属性、一一对应   → 字典    （一份素材的标题 / 类型 / 来源 / 标签）

再看一眼那个字典，你会发现「标签」这个键的值本身就是一个列表：

    "标签": ["民国", "师徒"]

这就是「字典里装列表」。反过来也可以「列表里装字典」：

    materials = [
        {"标题": "九门旧事", "字数": 3200},
        {"标题": "二月红传", "字数": 5100},
    ]

这叫套娃。它是所有数据结构的基本功，也是你项目里最核心的形态 ——
前端页面上那张素材列表，本质上就是这个样子。

五、红字怎么读（零基础救命指南）
============================================================

看到一片红字别关窗口 —— 那是程序在告诉你问题在哪。

比如你写了：

    print(1 + "a")

运行后会输出：

    Traceback (most recent call last):
      File "notes/day1_practice.py", line 12, in <module>
        print(1 + "a")
    TypeError: unsupported operand type(s) for +: 'int' and 'str'

读法：从最后一行往上读。

    最后一行      TypeError: ...        ← 错误类型 + 原因。这是最重要的一行
    倒数第二行    print(1 + "a")        ← 出错的那句代码，原样贴给你看
    再上面        line 12               ← 出错在第 12 行

零基础会遇到的三种报错，先认识一下：

  SyntaxError（语法错）

      原因：漏引号、漏括号、用了中文标点。
      最常见：中文引号 “ ”、中文冒号 ：、中文括号 （）
      解决：把标点切成英文输入法，重新打一遍。

  IndentationError（缩进错）

      原因：行首的空格不对。Python 靠缩进判断代码的从属关系。
      今天你几乎碰不到，因为还没学 if / for。明天会遇到。

  NameError（名字错）

      原因：用了一个没定义过的名字。
      常见：变量名拼错了；或者忘了先给它赋值。
      名字大小写也敏感：Site_name 和 site_name 是两个不同的名字。

一、为什么中间的空格没被去掉

先看你写的那段：

    text = " 老九门 二月红 "
    print(f"原样: [{text}]")
    print(f"去掉空格后: [{text.strip()}]")

真实输出（我跑出来的）：

    原样: [ 老九门 二月红 ]
    去掉空格后: [老九门 二月红]

注意方括号里的内容：开头的空格没了，结尾的空格没了，
但「老九门」和「二月红」中间那个空格还在。

原因一句话：strip 只去「两头」，不管「里面」。

把字符串拆开看，一目了然：

    位置 0   空格     ← strip 去掉
    位置 1   老
    位置 2   九
    位置 3   门
    位置 4   空格     ← strip 不碰（它在里面）
    位置 5   二
    位置 6   月
    位置 7   红
    位置 8   空格     ← strip 去掉

为什么这么设计？因为 strip 本来是拿来「清理脏数据」的 ——
从 Word 里复制一段话，前后常粘着看不见的空格，strip 一刀切掉。
它不想动句子内部，因为「老九门 二月红」中间那个空格可能是有意义的。

想让中间的空格也去掉，三种写法（都不改原 text，只给你新结果）：

    text.replace(" ", "")      → 老九门二月红     把每个空格换成「空」
    "".join(text.split())      → 老九门二月红     切成词，再用空串粘起来
    " ".join(text.split())     → 老九门 二月红    中间只留一个空格

第三个最常用 —— 它还能顺手把「连着好几个空格」压成一个。


二、函数语法：点号 和 括号，是两件不同的事

让某样东西「做个动作」，Python 有两种写法。

写法一，点号写法 —— 东西自己在做：

    text.strip()
    text.split()
    text.replace(" ", "")

    读作：text 执行 strip 这个动作。
    格式：谁 . 动作名 ( 材料 )

      谁     = 点号左边那个东西（这里就是 text）
      .      = 相当于「的」，表示这个动作属于前面那个东西
      动作名  = strip / split / replace
      ( )    = 执行的开关
      材料    = 括号里给的额外信息，可以不给

★ 最重要的一条认知：括号才是「执行」的开关。

    text.strip        ← 没括号：只是「提到」这个动作，什么都没发生
    text.strip()      ← 有括号：真的执行了

忘了括号，程序不报错，但结果不对 —— 这是新手最常见的坑之一。

写法二，括号写法 —— 拿个通用工具去量别人：

    print(text)
    len(text)
    int("22")

    读作：把 text 交给 len 去量一量。
    格式：工具名 ( 材料 )

为什么 len 不用点号？因为 len 不属于 text。
它是 Python 自带的通用工具，什么都能量 —— 字符串、列表、字典都行。
strip 则是字符串自己的本事，列表就没有 strip（列表没法「去掉首尾空格」）。

一句话判断该用哪种：

    这个动作是「这个东西特有的本事」 → 点号写法   text.strip()
    这个动作是「谁都能用的通用工具」 → 括号写法   len(text)


三、括号里放什么，结果不一样

同一个函数，括号里空着和给东西，干的事完全不同：

    s = "  陈皮阿四  "

    s.strip()        → [陈皮阿四]       空着 = 两头的空白都去
    s.lstrip()       → [陈皮阿四  ]     只去左边（l = left）
    s.rstrip()       → [  陈皮阿四]     只去右边（r = right）

括号里给什么，就用什么当「刀」：

    text.split()      → ['老九门', '二月红']     不填 = 按空白切
    text.split("月")  → [' 老九门 二', '红 ']    按「月」这个字切
    "-x-".strip("-")  → [x]                     只去两头的「-」

注意最后一条：strip 括号里放的是「一堆字符」，不是一整段文字。
strip("-") 的意思是「两头碰上是 - 就切掉」，不是「切掉 - 这个字符串」。


四、逐行讲你截图里那四行

第 1 行   print(f"原样: [{text}]")
    f"..." 是 f-string：引号前那个小写 f 是开关，让大括号里的东西被换成它的值。
    外面那对 [] 是我故意加的「相框」 —— 用来让你看清首尾有没有空格。
    不加框的话，末尾的空格肉眼根本看不出来。

第 2 行   print(f"去掉空格后: [{text.strip()}]")
    text.strip() 先把两头空白去掉，得到一个新字符串，
    再把这个新结果塞进 f-string 显示出来。
    重要：strip 不会改掉 text 本身，它是「生成一个新的给你」。

第 3 行   print(f"按空格切开后: {text.split()}")
    输出 ['老九门', '二月红']。
    外面是方括号、里面是带引号的词 —— 说明结果已经**不是字符串，而是列表**了。
    切一次，一个字符串变成一堆词。
    方括号 + 逗号 = 列表，这个形态先认下，练习 5 会细讲。

第 4 行   print(f"一共几个字:{len(text)}")
    输出 9。
    明明只有 5 个汉字，为什么是 9？因为三个空格也都算字符。
    len 数的是「字符个数」，不是「汉字个数」。
    想让空格不占数：len(text.strip())，先去掉两头再数。


五、自己动手验一下

把下面几行贴进你的练习文件里跑（改完记得 Ctrl+S）：

    print(len(text))
    print(len(text.strip()))
    print(text.replace(" ", ""))
    print(" ".join(text.split()))

想一想：前两行的结果一样吗？为什么？

（答案：9 和 7，不一样。差的正是两头那两个空格。
中间那个空格谁都没去掉，所以它一直在里面 —— 这就是你一开始的困惑。）


六、这两个函数以后在墨阁里干什么用

不是白学，你项目里马上要用：

    strip()  导入素材时，文件名、正文首尾常带换行和空格，
             入库前统一 strip 一下，标签才不会变成「 九门 」（带空格的那种）
    split()  把一段素材按空行/标点切成小块 —— 将来做 RAG 检索就是靠它切片的
    len()    页面上那个「一共多少字」的统计，就是一堆 len() 加起来
