模型设置

填哪家的 API Key，就能用哪家判素材。填完先「测试」验通不通，再「保存」。

充的是第三方的额度（硅基流动、各种中转站）也能用 —— 选一个预填好地址，把 Key 粘进去就行，地址和模型名都能自己改。
Key 只写在你本机的 data/models.json，界面上永远只显示打码后的样子。 data/ 整个目录都在忽略名单里，不会进公开仓库。
换 Key：直接在框里粘新的、点保存就覆盖了。
撤掉 Key：点那条上的「清空密钥」—— 地址和备注留着，只把钥匙抹掉。 删掉整条也行，但那样这些设置得重填。
「测试」会往那家服务商发一句「在吗」，确认地址、模型名、Key 三样都对 —— 这比跑完 600 张卡才发现填错了省事得多。
