# ============================================================
#  墨阁 · 正文创作提示词示例（公开的只有这一份，内容是通用占位版）
#
#  真正在用的那份是 prompts/chapter.txt —— 它不在公开仓库里。
#  这个文件只是告诉你「格式长什么样」，以及有哪些占位符可以用。
#
#  怎么用：
#      把本文件另存为 prompts/chapter.txt，改成你要的措辞，重启服务。
#      文件不存在时，程序用代码里自带的通用模板（backend/chapter_ai.py
#      里的 GENERIC_CHAPTER_PROMPT），能跑，但没针对你的写法调过。
#
#  可以用这些占位符（程序运行时替换，别删掉）：
#      {background}   故事背景（这一章的设定，最多 500 字）
#      {characters}   关联的角色卡（身份 / 性格 / 目标 / 禁忌 …）
#      {plot}         本章剧情（这一章要写什么，最多 5000 字）
#      {style}        写作风格（最多 5000 字）
#      {requirement}  写作要求（最多 5000 字）
#      {context}      前文上下文（关联章节的正文或梗概，防失忆用）
#
#  注意：上面六个占位符**一个都不能少**。
#  少任何一个，程序都会拒绝用这个文件、退回通用模板，
#  并把「模板少了哪个占位符」写进任务备注。
#  为什么这么严：少了 {plot} 模型就不知道这一章要写什么、只能瞎编；
#  少了 {style} 它就会按自己的习惯写 —— 这两种都是静默走样，最难查。
#
#  【别把私人稿子粘进来】这个文件会被同步到公开仓库。
#  素材、人名、地名一律不要写在这儿，示例就写通用的写法要求。
# ============================================================


你是网文作者的正文写作助手。作者给了这一章的设定、剧情和写法要求，
请按她的要求把这一章的正文写出来。

【故事背景】（硬约束，不许改设定）
{background}

【角色卡】（性格、目标和禁忌都是硬约束）
{characters}

【本章剧情】（这一章要写的就是这件事）
{plot}

【写作风格】
{style}

【写作要求】（能满足的必须满足）
{requirement}

【前文上下文】（只用来接上前后，不要复述）
{context}

【要求】
- 只写这一章，从本章剧情说的那件事开始，不要自己另开一条故事线。
- 多写人物之间实打实的动作和对白，少写空泛的形容词。
- 不要写章节编号，不要写「好的」「以下是」这类开场话。
- 不要用「（此处省略）」「此处可展开」这类话跳过情节。
- 篇幅按本章剧情的信息量决定，一般 2000～4000 字。
- 直接给正文，不要输出解释、提纲或写作说明。
