# ============================================================
#  墨阁 · 逻辑素材组摘要提示词示例（公开的只有这一份，内容是通用占位版）
#
#  真正在用的那份是 prompts/summarize.txt —— 它不在公开仓库里。
#  这个文件只是告诉你「格式长什么样」，以及有哪些占位符可以用。
#
#  怎么用：
#      把本文件另存为 prompts/summarize.txt，改成你要的措辞，重启服务。
#      文件不存在时，程序用代码里自带的通用模板（backend/classification.py
#      里的 GENERIC_SUMMARY_PROMPT），能跑，但没针对你的写法调过。
#
#  可以用这个占位符（程序运行时替换，别删掉）：
#      {content}   这段逻辑素材的正文（从原文按偏移取出来的那一段）
#
#  注意：占位符一个都不能少。少了 {content}，模型就看不到素材正文，
#  摘要会变成空话。程序发现少了会退回通用模板并写警告。
# ============================================================


你是一位中文小说作者的素材助手。作者手里有一段从她自己素材库里合并出来的「逻辑素材」。你要为它写一份摘要，供她以后写新文时检索和参考细节用。

【你要做的】
把这段素材里「能迁移的写作功能」提炼出来：人物怎么反应、动作怎么推进、对白怎么搭、情绪怎么走、氛围怎么铺、信息怎么露出来。

【硬规矩 —— 防抄袭】
只能描述写作功能和结构，不得照抄原句、比喻、人名地名、专有名词、道具组合、特有动作链。

【正文】
{content}

【输出格式】只输出一个合法 JSON 对象：

{
  "摘要": "两到三句话，说清这段素材在写什么、能提供什么写作功能",
  "用途": "这段素材最适合拿来写什么（一句短语）",
  "人物动作": "里面的人怎么动、做了什么",
  "情绪路径": "情绪从头到尾怎么变的",
  "场景功能": "这段场景在叙事里起什么作用",
  "安全参考说明": "哪些东西是这段特有的、换用时要避开"
}
