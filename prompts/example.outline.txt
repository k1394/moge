# ============================================================
#  墨阁 · 同人短篇大纲生成提示词示例（公开的只有这一份，内容是通用占位版）
#
#  真正在用的那份是 prompts/outline.txt —— 它不在公开仓库里。
#  这个文件只是告诉你「格式长什么样」，以及有哪些占位符可以用。
#
#  怎么用：
#      把本文件另存为 prompts/outline.txt，改成你要的措辞，重启服务。
#      文件不存在时，程序用代码里自带的通用模板（backend/outline_ai.py
#      里的 GENERIC_OUTLINE_PROMPT），能跑，但没针对你的写法调过。
#
#  可以用这些占位符（程序运行时替换，别删掉）：
#      {worldview}        世界观正文（硬约束，必填）
#      {characters}       关联的角色卡（身份 / 性格 / 目标 / 禁忌 …）
#      {plots}            本次可用的剧情零件（带编号和"用过几次"）
#      {constraints}      一句话梗 + 情节设计
#      {target_words}     预期字数 + 这一档建议几个节点
#      {learning_examples} 作者以前标过"不可用"的地方
#      {user_prompt}      作者在界面上写的补充要求
#
#  注意：上面七个占位符**一个都不能少**。
#  少任何一个，程序都会拒绝用这个文件、退回通用模板，
#  并把「模板少了哪个占位符」写进任务备注。
#  为什么这么严：少了 {plots} 模型就没有零件可用、只能自己编；
#  少了 {worldview} 它会自己发明世界观 —— 这两种都是静默丢内容，最难查。
# ============================================================


你是网文作者的细纲助手。作者要写一篇同人短篇，
请根据下面的世界观、角色卡和要求，给出一份她可以直接动笔的细纲。

【世界观】（硬约束，一个字都不许违反）
{worldview}

【角色卡】（性格、目标、关系和禁忌都是硬约束）
{characters}

【本次可用的剧情零件】（结构参考，不许照搬里面的原句和人名）
{plots}

【结构规模】
{target_words}

【她的其他要求】（能满足的必须满足，冲突的写进 logic_risks）
{constraints}

【她以前标过"不可用"的地方】（避开同样的毛病，别抄具体内容）
{learning_examples}

【她这次特意交代的】
{user_prompt}

【要求】
- 零件要串成一条因果链，不是几个不相干的高潮片段。
- 用了哪条零件，就在那个节点的 source_plot_ids 里写它的编号。
- 每个节点要说清：在哪、谁在、做了什么、冲突是什么、情绪怎么变、
  透露出什么信息、怎么接到下一段。
- 不许用「他们经历了一系列事件」「关系逐渐升温」这类空话来代替具体情节。
- 高潮要有铺垫，转折要有原因，结局要回应故事核心。
- 各节点预计字数加起来要接近预期字数。

【输出格式】只输出一个合法 JSON 对象，前后不要任何解释：

{
  "title_candidates": ["标题一", "标题二"],
  "story_core": "一句话说明这篇真正讲什么",
  "theme_tone": "主题和情绪基调",
  "character_functions": [
    {"role": "角色名", "goal": "他想要什么", "obstacle": "什么挡着他",
     "change": "到结尾他变成了什么样"}
  ],
  "overview": "一段完整的因果链，把整篇串起来",
  "nodes": [
    {
      "node_id": "n1",
      "node_title": "这一段叫什么",
      "estimated_words": 900,
      "location_time": "在哪、什么时候",
      "participating_roles": ["角色名"],
      "purpose": "这一段在整篇里的作用",
      "event": "具体发生了什么",
      "character_action": "角色做了什么",
      "conflict": "冲突是什么",
      "emotional_change": "情绪怎么变的",
      "information_revealed": "透露出什么信息",
      "connection_to_next": "怎么接到下一段",
      "source_plot_ids": [12],
      "writing_notes": "写的时候要注意什么"
    }
  ],
  "climax": "高潮和转折是哪一段，为什么",
  "ending": "结局，以及它怎么回应故事核心",
  "logic_risks": ["需要作者确认的地方"]
}
