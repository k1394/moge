# 墨阁 Moge · 公开展示版

给网文 / 同人短篇作者用的 AI 写作助手站。

> **这是公开展示版，只包含框架与可复用的通用代码。**
> 真实提示词、素材库、产品逻辑在另一个私有仓库里，不在本仓库。

---

## 为什么分两个仓库

| | 公开展示版（本仓库） | 完整版（私有） |
|---|---|---|
| 内容 | 目录结构、接口写法、通用工具、前端页面 | 全部代码 + 真实提示词 + 素材库设计 |
| 用途 | 给别人看「这个项目是怎么搭的」 | 实际在用的产品 |
| 可见性 | Public | Private |

**不放在这里的东西**（是有意为之，不是缺失）：

- 真实提示词 —— 一个写作助手站真正值钱的资产
- 素材库内容、人设库、剧情库
- 调参记录、A/B 实验数据、运营数据

本仓库 `prompts/` 下只有几个 `example.*.txt`，是**格式示例**，
用来说明提示词怎么组织（有哪些占位符、输出什么格式），内容是占位的，不参与生产。

---

## 技术栈

- **后端**：Python 3.13 + FastAPI
- **数据库**：SQLite（素材 / 账号 / 分类 / 剧情 / 大纲 / 人设卡 / 正文），Chroma（向量检索，规划中）
- **前端**：原生 HTML / CSS / JS（暂不上框架，先求跑通，单文件）
- **大模型**：走 OpenAI 兼容接口，可同时配多家服务商与中转站；支持流式输出

## 本地运行

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m uvicorn backend.main:app --port 8000
```

浏览器打开 http://localhost:8000

Windows 下也可以直接双击 `启动墨阁.bat`。

### 桌面版素材浮窗（可选）

网页里的浮窗只能浮在墨阁这个页面上面 —— 浏览器不允许网页画到自己窗口之外，
这是浏览器的安全模型，不是代码问题。想让它**盖在其它写作软件上面**：

```bash
.venv/Scripts/python.exe -m pip install pywebview pystray pillow
```

然后双击 `启动素材浮窗.bat`。它开一个无边框、始终置顶的真窗口，
顺手把上面那个服务也拉起来：

- **拖动**：按住标题栏拖；**缩放**：拖右下角；**最小化**：标题栏的 `–`
- 位置和大小自动记住，下次启动回到原样
- 全局快捷键（默认 `Ctrl+Alt+M`，被占用时自动往后退）显示 / 隐藏
- 托盘图标右键可以显示 / 隐藏 / 退出；隐藏是"收起来"不是关掉，内容不丢
- 只保证标题栏留一条在屏幕里（拖得回来），不做硬贴边 —— 多显示器接法太多

## 素材解析模块

`backend/parsers.py` —— 把各种格式的素材文件读成纯文本，供后续入库与检索使用。

- 支持 `.txt` `.md` `.docx` `.pdf` `.xlsx` `.xlsm`
- 全部**本地解析**，不调用任何云服务
- 统一返回结构，**从不抛异常** —— 批量导入遇到坏文件会跳过并记录，
  不会因为一个文件失败而中断整个流程

实测中处理掉的两个真实问题：

1. **docx 关系条目损坏**：某些 WPS 编辑过的文档里残留 `Target="../NULL"` 的坏关系，
   `python-docx` 会直接报错。已加兜底路径：常规方法失败时直接解 zip 读
   `word/document.xml`，正常提取文字。
2. **扫描件 PDF 无文字层**：这类 PDF 里其实是图片，提取结果为 0 字。
   已在返回值里明确标注，后续需接 OCR 才能处理。

## 几个工程上的选择（可公开的框架层）

- **流式输出**：模型一边吐字、页面一边显示，而不是等整段返回。
  后端一个内存多路通道把分块推给订阅者；订阅者挂起等待，不忙等轮询。
- **耗时记账**：每次调用（成功或失败）都记下来，界面能回答
  「这次首字等了多久、总共多久、用了多少 token」。首字耗时没量到就记 0，
  求平均时必须排除 —— 混进去会把平均值压低，得出"这个模型很快"的错误结论。
- **提示词分层**：代码里的通用模板（可公开）/ 仓库外的真实提示词 /
  公开的格式示例。模板缺占位符时拒绝使用并退回通用版，把警告写进任务备注，
  绝不静默丢内容。
- **手填内容与模型返回分开处理**：手填的过长直接报错（不静默截断）；
  模型返回的过长则截断 + 记警告（花过钱的东西不因小瑕疵整份作废）。
- **超时与重试分两套**：短任务用默认值，长任务自己传更长的超时和更少的重试
  —— 最坏等待 = 超时 × 重试次数 + 退避，界面要把这个说清楚。
