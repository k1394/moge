# 墨阁 Moge · 公开展示版

给网文 / 同人短篇作者用的 AI 写作助手站。

> **这是公开展示版，只包含框架与可复用的通用代码。**
> 真实提示词、素材库、产品逻辑在另一个私有仓库里，不在本仓库。

---

## 为什么分两个仓库

| | 公开展示版（本仓库） | 完整版（私有） |
|---|---|---|
| 内容 | 目录结构、接口写法、通用工具、前端页面 | 全部代码 + 真实提示词 + 素材库设计 |
| 用途 | 给别人看「这个项目是怎么搭的」 | 实际在用的产品 |
| 可见性 | Public | Private |

**不放在这里的东西**（是有意为之，不是缺失）：

- 真实提示词 —— 一个写作助手站真正值钱的资产
- 素材库内容、人设库、剧情库
- 调参记录、A/B 实验数据、运营数据

本仓库 `prompts/` 下只有一个 `example.prompts.txt`，是**格式示例**，
用来说明提示词怎么组织，内容是占位的，不参与生产。

## 技术栈

- **后端**：Python + FastAPI
- **数据库**：SQLite（素材 / 分类 / 人设卡），Chroma（向量检索，规划中）
- **前端**：原生 HTML / CSS / JS（暂不上框架，先求跑通）
- **大模型**：阿里云百炼 / 通义千问

## 本地运行

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m uvicorn backend.main:app --port 8000
```

浏览器打开 http://localhost:8000

Windows 下也可以直接双击 `启动墨阁.bat`。

## 素材解析模块

`backend/parsers.py` —— 把各种格式的素材文件读成纯文本，供后续入库与检索使用。

- 支持 `.txt` `.md` `.docx` `.pdf` `.xlsx` `.xlsm`
- 全部**本地解析**，不调用任何云服务
- 统一返回结构，**从不抛异常** —— 批量导入遇到坏文件会跳过并记录，
  不会因为一个文件失败而中断整个流程

实测中处理掉的两个真实问题：

1. **docx 关系条目损坏**：某些 WPS 编辑过的文档里残留 `Target="../NULL"` 的坏关系，
   `python-docx` 会直接报错。已加兜底路径：常规方法失败时直接解 zip 读
   `word/document.xml`，正常提取文字。
2. **扫描件 PDF 无文字层**：这类 PDF 里其实是图片，提取结果为 0 字。
   已在返回值里明确标注，后续需接 OCR 才能处理。
