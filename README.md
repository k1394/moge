# 墨阁 Moge

写作素材与方法库 —— 给网文 / 同人短篇作者用的 AI 助手站。

## 这是什么

一个从零开始、边学边做的项目。目标不只是学技术，而是做出一个真实可用、
有真实用户的网站。同时作为秋招求职的项目作品。

## 技术栈

- 后端：Python + FastAPI
- 数据库：SQLite（素材 / 分类 / 人设卡）
- 向量库：Chroma（语义检索，阶段三启用）
- 前端：原生 HTML（暂不上框架）
- 大模型：阿里云百炼 / 通义千问

## 本地运行

```bash
# 1. 进入项目目录
cd G:/docker/moge

# 2. 启动服务（虚拟环境已经建好）
./.venv/Scripts/python.exe -m uvicorn backend.main:app --port 8000

# 3. 浏览器打开
# http://localhost:8000
```
