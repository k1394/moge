========================================
  墨阁 · 素材浮窗
========================================

双击「启动素材浮窗.bat」之后：

  浮窗会出现在屏幕右侧，盖在其他软件上面，可以一边码字一边看素材。
  它会顺手把墨阁服务也拉起来（第一次要等十几秒，之后几秒就好）。

  刚启动时窗口里先显示「正在启动墨阁服务…」，起来了就自己换成素材
  列表，不用管那个一闪而过的黑窗口。

----------------------------------------
  浮窗怎么使（标题栏那行小字是同一个意思）
----------------------------------------

  移动     ：按住标题栏（最上面那条）拖。
  放大缩小 ：按住右下角那个小三角拖。
             拉不小到比 380x300 还小（再小内容就挤成一条线了）；
             最大也就到整块屏幕那么大。
  最小化   ：标题栏右边的「–」，缩到任务栏里。
             叫回来的三条路：按快捷键、点任务栏上的图标、托盘图标右键。
  收起来   ：标题栏右边的「×」。这个跟最小化不一样 —— 它连任务栏都不占，
             再按一次快捷键就回来（内容都在，不用担心丢）。
  显示/隐藏：全局快捷键（到底是哪个键，浮窗标题栏上写着）
             或者右下角托盘图标上点右键
  彻底退出 ：托盘图标右键 - 退出

  位置和大小会自动记住：拖到哪儿、拉多大，下次双击还是那样。
  拖的时候可以拖到屏幕边上、只露一条标题栏也行 —— 只要标题栏还看得见，
  就永远拖得回来。要是整个拖出屏幕了，它会自己弹回来一点。

----------------------------------------
  下面这段只有出问题时才用得上
----------------------------------------

如果提示「找不到 .venv\Scripts\pythonw.exe」，
说明虚拟环境还没装好。在这个目录里依次跑这两条：

    python -m venv .venv

    .venv\Scripts\python.exe -m pip install -r requirements.txt

装完再双击一次。

如果浮窗出来了但里面说服务没起来，去看项目目录（就是本文件所在
文件夹的上一层）里的这两个日志：

    data\float_backend.log   墨阁服务自己报的错
    data\float_host.log      浮窗自己报的错
